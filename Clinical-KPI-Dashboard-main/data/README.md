# Clinical Dataset Description

This folder contains the synthetic clinical dataset used in the **Clinical KPI Dashboard** project.

## Files

### `clinical_data.csv`
A fully synthetic dataset created for educational and portfolio purposes.  
It contains anonymized rehabilitation data including:

- Patient demographics  
- Injury types  
- Rehabilitation start and end dates  
- Number of therapy sessions  
- Pain scores (initial and final)  
- Mobility scores (initial and final)

## Purpose

This dataset is used to:

- Demonstrate ETL workflows  
- Perform clinical KPI calculations  
- Build Power BI dashboards  
- Practice healthcare data analysis  
- Showcase data storytelling skills

## Notes

- All data is **synthetic** and does **not** represent real patients.  
- The dataset can be safely shared publicly.  
- Additional rows can be generated if needed for extended analysis.
